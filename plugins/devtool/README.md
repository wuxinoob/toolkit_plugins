# 开发助手 (DevTool)

Windows 环境下高频开发与系统实用工具集成插件。

## 核心特性

- **端口占用探测与强杀**：基于 Windows TCP/UDP 扩展表，一键识别占用端口的进程名称、PID 与路径，支持优雅终止与强制关闭。
- **文件与目录锁排查**：排查文件或文件夹被哪些进程锁定，解决“文件正在被另一程序使用无法删除”的问题。
- **PATH 环境变量诊断**：可视化解析系统与用户 PATH 变量，自动检测失效路径、重复路径并提供优化建议。
- **系统防休眠 (Awake)**：防止长时间运行编译任务或下载时屏幕变暗或系统睡眠。
- **Hosts 文件极简编辑**：支持快速编辑 Windows 系统 hosts 文件，自动保存备份 (`hosts.bak`)。

## 安装方式

通过 Toolkit 插件商店一键安装，或解压至 `%APPDATA%\com.tan18.toolkit\plugins\devtool`。
