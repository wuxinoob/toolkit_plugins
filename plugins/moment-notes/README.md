# 拾光便签 (Moment Notes)

基于 WebDAV 同步的高颜值桌面便签工具。

## 核心特性

- **多窗口架构与置顶浮窗**：主界面分类管理，支持单独将某条便签弹出为置顶小浮窗。
- **双向实时同步**：基于 Toolkit 内部总线，浮窗编辑与主窗口双向无缝更新。
- **WebDAV 云端同步**：支持坚果云、Nextcloud 等任何标准 WebDAV 服务端，数据安全可控。
- **富文本与多格式**：支持清单、代码块、图片缓存与自动归档。

## 安装方式

通过 Toolkit 插件商店一键安装，或解压至 `%APPDATA%\com.tan18.toolkit\plugins\moment-notes`。
