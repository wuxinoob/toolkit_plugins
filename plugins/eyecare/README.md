# 护眼助手 (EyeCare)

定时护眼与防沉迷提醒工具。

## 核心特性

- **自绘桌面悬浮胶囊**：优雅悬浮窗实时展示本轮工作倒计时，支持拖拽移动与状态切换。
- **全屏柔和遮罩提醒**：倒计时结束自动呼出休息遮罩，引导远眺放松。
- **键鼠空闲自动检测**：通过轻量 Sidecar (`idle.exe`) 检测用户空闲状态，离开电脑时自动暂停或重置计时。
- **点击穿透与防误触**：支持设置锁定与穿透模式，不干扰全屏工作与游戏体验。

## 安装方式

通过 Toolkit 插件商店一键安装，或解压至 `%APPDATA%\com.tan18.toolkit\plugins\eyecare.demo`。
